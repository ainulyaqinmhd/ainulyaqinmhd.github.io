Speculative Kano Analysis

Ask each stakeholder two questions about every feature of your 2045 object: how they feel if it is there, and how they feel if it is not. The analysis sorts each feature into Must-be, Performance, Attractive, Indifferent or Reverse, for everyone and for each stakeholder group.

Example loaded: the 2045 restaurant robot, with 8 classmates playing 4 stakeholder roles. Study it, then clear it to start your own.

1Features

Up to 12. Write each as a benefit the person would notice.

2Stakeholder groups and respondents

Classmates answer as their role card, not as themselves.
Stakeholder groups (segments)

3Answers

Functional: “How do you feel if the object has this feature?” Dysfunctional: “How do you feel if it does not have it?” Importance: 1 (not important) to 10 (very important).

Bring in answers from a spreadsheet (CSV)

Use the same columns as the Responses sheet of the Kano workbook: Feature, User, Functional, Dysfunctional, Self-stated Importance, and optionally Segment. Features are matched by code (F1, F2…) or name; new respondents are added. In Excel, choose File › Save As › CSV UTF-8.

Not sure how to start? Download the template. It has one row for every feature and respondent you have set up in steps 1 and 2, with features listed by code (F1, F2…). Fill in the Functional and Dysfunctional columns with one of: I like it, I expect it, I am neutral, I can tolerate it, I dislike it. Importance is a number from 1 to 10. Add more rows for more respondents, and leave out rows nobody answered.

4Results

4aContinuous analysis

Averages the answer scores, so strong and mild feelings both count

Kano map

Each bubble is a feature, placed by average dysfunctional (X) and functional (Y) score. Bigger bubbles mean higher self-stated importance. Questionable answers are left out of the averages.

4bDiscrete analysis

Sorts every answer pair with the Kano table, then counts the categories

Answer mix

Each bar is a feature, split by the share of respondents in each category. The outlined part is the most common category. When the two analyses disagree, people are split on that feature.
